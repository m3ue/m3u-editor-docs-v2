# ElfHosted

[ElfHosted](https://store.elfhosted.com/product/m3u-editor/) offers M3U Editor as a paid, managed instance. They run and update it for you, so there's no server, Docker, or configuration to look after.

Everything in these docs applies, except the parts about installing and configuring the containers.

:::note M3U Proxy isn't available
ElfHosted instances don't include [M3U Proxy](/docs/proxy/overview). For proxied playback, connect a [MediaFlow Proxy](/docs/advanced/settings-reference#mediaflow-proxy) instead, under **Settings → Integrations → MediaFlow Proxy**.
:::
